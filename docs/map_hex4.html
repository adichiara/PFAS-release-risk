PFAS release risk, Massachusetts

Relative risk of a reported PFAS release per km², by 4 km² hexagon. Built only from public data.

Preliminary. Trained on 194 located PFAS releases (MassDEP PFAS release list). Scores rank areas relative to each other; they are not probabilities of contamination.

Method, validation and data sources · PFAS in drinking water

How well it validates

Model: logistic. Scores shown are out-of-fold: each 4 km² hexagon was scored by a model trained without its town.

Cells have equal area, so the baseline uses population and housing density. Denser places see more reported releases, so the useful signal is how far the model gets beyond it.
