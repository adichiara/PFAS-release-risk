PFAS release risk in Massachusetts

Relative risk of a reported PFAS release for each of the state's 5,109 census block groups, built only from public data.

How well it validates

Five-fold cross-validation that holds out whole towns, repeated __REPEATS__ times. Larger block groups see more reported releases, so each model is compared with baselines that use size alone. The highlighted row is the model shown on the map.

Method

  • Unit: 2020 census block groups, in Massachusetts State Plane meters.
  • Response: MassDEP reportable releases (RTNs) with PFAS as a chemical, located by matching addresses to MassGIS address points.
  • Features: counts inside, counts within 2 km and distance to the nearest fire station, MassDEP major facility, hazardous-waste generator, air-permitted facility and underground storage tank; landfills; aquifers; major-road density; population and housing density.
  • Map scores are out-of-fold: each block group is colored by a model trained without its town, so known release sites are not simply echoed back.
